# WhereWePraying?

V0.1 of the WhereWePraying web app.

## Current scope
- Responsive homepage and navigation
- Qur'an reader foundation
- Daily Islamic journal with local device saving
- Dua & Dhikr category foundation

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Cloudflare Pages build output directory: `dist`

> The approved Portal 5 logo asset should be added as the official brand image. The temporary interface mark must not be treated as a redesign or replacement.
